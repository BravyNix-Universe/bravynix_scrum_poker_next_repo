# Bravynix Scrum Poker

Free, no-login Scrum Poker for poker.bravynix.com. Product and design documents are in [`doc/`](doc/), and the Stitch screens are in [`design/`](design/).

Built with Next.js (App Router), React, TypeScript and Tailwind CSS, exported as static files (`output: "export"`) for Hostinger. The code follows Clean Architecture; see [ARCHITECTURE.md](ARCHITECTURE.md).

## Requirements

Node.js 22.12 or later (see `.nvmrc`).

## Commands

```bash
npm install          # install dependencies
npm run dev          # local dev server at http://localhost:3000
npm run check        # typecheck, lint, format check and tests (run before every commit)
npm test             # unit and component tests (Vitest)
npm run lint:fix     # fix lint issues, including import order
npm run format       # format with Prettier
npm run build        # static export into out/
npm run avatars      # regenerate the avatar SVGs in public/avatars
```

Upload the contents of `out/` to the site's `public_html` to deploy.

## Project layout

```text
src/
  domain/          pure business rules (deck, results, limits, room IDs and links)
  application/     use cases, the room referee and the ports they need
  infrastructure/  adapters for browser APIs (Web Crypto, Web Storage) and the preview room session
  composition/     wires adapters to ports
  app/             Next.js routes
  features/        feature screens and hooks (landing, create-room, my-rooms, room)
  components/      shared UI kit and layout
  lib/  config/    UI helpers and site settings
  test/            test setup and fakes
public/avatars/    avatar images, generated by scripts/generate-avatars.mjs
```

## Preview mode

Until live rooms land (Phase 5), a room runs as an in-tab preview: teammates are simulated and nothing leaves the browser tab. They join, vote and open their cards when you reveal. Open the invite link in a private window to see the participant view, where a simulated host also reveals and moves through the stories.

To review the connection screens without a network, open **Connection details** (the connection indicator in the top bar, or the room menu) and pick a situation under **Preview: act out a situation**: a dropped connection, the host stepping away, 24 more people joining, or each "can't connect" page. Those pages' **Try again** brings you back to the room.
